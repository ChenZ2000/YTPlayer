# 结构化信息的网页阅读区域

用户信息、键盘快捷键参考、关于易听、艺人详细介绍、更新提示和更新检查结果共用 `Forms/AccessibleDocumentView.cs`。复用已有 WebView2，不新增 NuGet 包、JavaScript 框架或网络资源。

## 阅读和焦点

- 用户信息按基本资料、身份与会员、个性签名、统计信息、时间信息分组，使用一级/二级标题、段落及无序列表。
- 快捷键按原文的三个类别分别显示为数据表格，提供标题、表格名称、列标题和行标题，保留全部快捷键和说明。
- 关于文档保留列表及链接；艺人介绍保留章节和段落；更新信息使用条目列表。
- 正常 Tab 顺序中，整个文档区域只有一次停留。浏览器内的链接不增加 Tab 停留点，仍可通过屏幕阅读器的链接导航或鼠标使用；链接在系统默认浏览器打开。
- 文档使用正常 HTML 语义，不使用 `role="application"`，也不截获 H、L、T 等阅读快捷键。NVDA 的浏览模式负责单键导航。
- 文档只将 Tab、Shift+Tab 和 Esc 转交给原生窗口。Tab/Shift+Tab 返回相邻的原生控件，Esc 请求关闭所在窗口，并保留窗口自己的关闭/取消逻辑。

## 性能和容错

- 只在文档实际可见时异步初始化；未显示的对话框和选项卡不创建浏览器。
- 多个文档复用一个 WebView2 environment 和浏览器进程，窗口关闭后释放各自的 controller。
- 内容完全在本地生成。数据更新时复用现有页面，保留滚动位置，不重复导航；相同内容不会重复更新。
- 配色和字体跟随应用主题，支持高对比度和浏览器缩放；长文本可以换行。
- 加载期间提供即时可读文本。已在内容区的焦点在加载完成后移交 HTML；位于其他控件的焦点保持原位。
- 缺失运行时、初始化失败或渲染进程出错时回退为只读文本，原生按钮仍可用。此时不提供网页单键导航。
- 外部资料只按文本转义；只有内置文档按受支持的 Markdown 结构转换。关闭远程资源、下载、页面权限和脚本注入通道；文档使用独立的 InPrivate profile。
- 普通短提示、实时识曲状态、一起听的地址/短状态继续使用原生控件，避免为这些内容启动浏览器。

## NVDA 人工验收

运行上述测试程序并传入 `--preview`，或直接在易听中打开对应窗口。验收程序提供独立样例的用户信息、快捷键、关于和长文档四个选项卡。

1. Tab 到文档，确认 NVDA 将其识别为文档并进入浏览模式。
2. 用户信息中用 H/Shift+H、2、L、I 阅读标题和列表项；快捷键中用 T 及 Ctrl+Alt+方向键阅读表格与行列标题。
3. 用 Tab 离开文档到原生按钮，再用 Shift+Tab 返回；从文档向前移动时也应到前一个原生控件。
4. 关于文档中用 K 阅读链接并确认可激活；继续 Tab 时不应逐个停在所有链接上。
5. 确认 Ctrl+C 复制、放大后的换行和 Esc 关闭体验。

本轮实际桌面检查已确认 WebView2 无障碍树包含“文档、标题、列表、列表项目”，并检查了可见布局。桌面自动化工具两次报 `failed to activate captured window`，未能完成真实 NVDA 按键及语音输出的验收；上述按键步骤仍需人工复核，自动焦点断言不能代替这项验证。
