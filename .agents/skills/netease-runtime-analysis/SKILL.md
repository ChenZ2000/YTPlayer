# 网易云 API 动态分析

把运行时证据、请求契约、客户端修复和用户可见结果连接起来。先读当前仓库的 `AGENTS.md`；本 skill 不扩大目录写入、账号使用或对外操作的授权范围。以下路径以本仓库根目录为基准。

## 执行顺序

1. **收敛问题**：写下触发动作、实际现象、预期结果及可证伪的判断。检查现有源码、测试和脱敏记录，先复用已知结果。明确 APK 版本、Android API/ABI、Frida 客户端与服务端版本、账号权限、网络和音频来源。
2. **恢复环境**：按 [环境与挂钩](references/runtime.md) 检查 ADB、模拟器、代理证书及 Frida。只用动态观察；不展开混淆 DEX/class，不进行全包反编译。一个具体挂钩/策略失败两次就记录失败并降到 OkHttp/Cronet 或原生 TLS/缓冲区层，不反复猜类名。
3. **捕获最小闭环**：一次只触发一个动作。同步记录进程、时间、路径、请求结构、HTTP 状态、返回体长度、业务码和 UI 结果；在加密前/解密后观察内存。先按 [传输契约](references/transport.md) 排除会话、Host、编码与解密问题，再判断业务逻辑。
4. **按模块取证**：一起听读 [房间与同步](references/listen-together.md)；听歌识曲读 [音频指纹](references/recognition.md)；计数和未缓存跳转读 [播放验证](references/playback.md)。只加载当前模块需要的参考文件。
5. **小范围修复**：复用生产传输层。约束取消、超时、并发、账号归属和资源释放；新增回归必须能抓住此次缺陷。不要以抓包脚本替代生产实现，不要根据单次成功重写整套播放架构。
6. **验证并归档**：先跑离线回归，再按授权执行最小真实账号实验。输出字段类型/单位、状态机、证据位置、已覆盖场景及剩余边界。可复用脚本进入 `Tests/`；凭证、带签名 URL、原始捕获和音乐素材只放忽略目录。结束后卸载 hook、恢复原代理设置、退出自己创建的测试房间，清理临时会话副本。

## 证据要求

- 将证据标为：**运行时观察**、**本实现实验**、**外部源码参考**或**未验证假设**。外部项目和旧 APK 的实现仅是线索；需要当前请求/响应和用户可见结果支撑结论。
- `HTTP 200`、业务 `code=200`、状态变更/统计入账是三个不同层次。不能把空响应当成功，也不能把一次服务端接受解释为即时更新总计数。
- 一起听用两个不同的已授权账号验证双向命令；同一账号的两个进程不能代替双账号互通。
- 识曲用同一 PCM、相同窗口和提交次数对照 Android JNI 与生产 .NET 链路；保留无匹配样本。不得从小样本宣称所有录音环境均达到官方命中率。
- 未缓存跳转必须先空缓存定位并解码，再下载完整文件作对照。记录取数范围和总字节，证明未先取完整首。字节 Range 不是“秒数 API”；没有证据时保留现有缓存架构。
- 不记录或提交 Cookie、令牌、完整房间邀请、用户标识或带签名媒体地址；只输出字段名、必要的类型、布尔匹配结果和脱敏摘要。实际捕获仍需检查嵌套 JSON/URL，不能假定过滤器完全覆盖隐私字段。

## 仓库验证入口

```powershell
# 自动寻找 VS MSBuild；也可传 -MSBuild <完整路径>。需要 .NET 10、Windows x64、FFmpeg。
pwsh -File scripts/Test-ProtocolRegression.ps1
```

此入口只运行 Debug 构建和离线回归，不登录、不建房、不提交真实听歌记录。真实实验命令见对应参考文件。提交或推送仅在用户授权时执行；开发检查点不改版本号、不创建标签、不触发发布工作流。
